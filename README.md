# 🛠️ Find Local Vendor Hub

**Find Local Vendor Hub** is a web-based platform built with **PHP, MySQL, HTML, CSS, and JavaScript** that connects users with nearby vendors and service providers.  
The goal is to make it easier for people to discover, contact, and rate vendors (like electricians, plumbers, or shop owners) in their local area.

---

## 🌍 Features

✅ **User Registration & Login**  
Users can sign up as:
- Regular Users  
- Product Vendors  
- Service Vendors  

Each user type has its own dashboard and role-based access.

✅ **Nearby Vendor Search**  
Find vendors near your location using distance-based filtering.

✅ **Google Maps Integration**  
View vendor locations directly on a map with clickable pins.

✅ **Vendor Ratings & Reviews**  
Users can rate vendors after service, and vendors can view their average rating.

✅ **Vendor Dashboard**  
Vendors can:
- Add or edit their service details  
- Update location and pricing  
- Manage ratings and profile information

✅ **Responsive Design**  
Fully mobile-friendly layout with clean UI.
